# My biostats blog
Blog with various post regarding biostatistical issues.

See here: https://stepanovic99.github.io/biostats_blog/

Workflow:
1) Create a new post with quarto, locally inside biostats_blog/posts/ by using the template .qmd file.
2) Render the quarto file
3) Upload all files inside biostats_blog/_site to this repo. Upload the content of the folder and not the folder itself.
